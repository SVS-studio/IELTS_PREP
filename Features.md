# 1. PRODUCT OVERVIEW

IELTS Prep AI is an AI-powered IELTS preparation platform designed to help students improve their English proficiency and prepare for the IELTS examination through structured practice, intelligent feedback, diagnostic assessments, and personalized progress tracking.

The platform combines all four IELTS skills into one unified learning environment.

### Core Value Proposition

- Practice all four IELTS skills in one platform.
- Receive AI-powered feedback.
- Identify weaknesses through diagnostic assessments.
- Track learning progress.
- Prepare through structured practice and mock examinations.

### Target Audience

- IELTS beginners.
- Intermediate English learners.
- Students preparing for IELTS Academic.
- Students targeting higher IELTS band scores.

# 2. CORE FEATURES

## 2.1 Authentication & User Management

Features:
- User registration.
- Email verification.
- User login.
- Google authentication (where configured).
- Secure authentication.
- User profile management.
- Session management.

User journey:
Registration → Email Verification → Level Selection → Plan Selection → Dashboard.

## 2.2 Onboarding & English Level Assessment

Users can select their estimated English proficiency level.

Supported CEFR levels:
- A1
- A2
- B1
- B2
- C1
- C2
- I don't know my level.

If the user selects "I don't know", the platform directs them to a diagnostic assessment.

Diagnostic sections:
- Grammar.
- Vocabulary.
- Reading.
- Listening.

Diagnostic options:
- Quick Diagnostic.
- Full Diagnostic.

The diagnostic result should help determine the user's starting proficiency level.
